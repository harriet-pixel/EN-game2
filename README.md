# 苔光之境 · Mosslight Adventure

桌面優先的像素 RPG 學習網站，無需 API 金鑰或外部套件。

## 啟動

Node.js 18 以上：

```sh
npm run dev
```

預設連接埠 3000，可使用 PORT 環境變數調整。`npm run build` 產出可部署於靜態網站服務的 `dist/`。

## 功能

- 12 格石階、骰子 1–6 點、逐格人物動畫與抵達後隨機挑戰。
- 每次自評答對獲得 25 EXP，每 100 EXP 升級；到達終點可重新探索。
- 批次上傳圖片（單張 20MB 以內，縮至最長邊 1600px）、資料夾分類、編輯題目答案、搜尋、批次移動與刪除。
- 使用 IndexedDB 儲存題庫與冒險進度。資料屬於此瀏覽器與網站來源；清除網站資料會移除進度，請保留原始圖片。
- 背景 `.background-layer`、石階 `.path-layer`、人物 `.character-layer` 為獨立圖層，可分別替換。森林背景為本地 SVG；角色為 CSS 像素圖。

這是純前端版本，沒有帳號、跨裝置同步或自動圖片文字辨識。圖片題目與答案可手動編輯。

## 持續冒險與設定

石階無終點，顯示視窗會隨旅人前進。✧ 為題目、✦ 為機會、☽ 為命運，停留的格子決定事件；機會可獲得經驗，命運可能獲得或失去少量經驗（不低於零）。事件不計入場景答對數。

「冒險設定」可分別設定微光森林、琥珀暮林與月影秘境的答對門檻（1–1000 題）；完成後開啟魔法陣，再擲骰前進一格穿越魔法陣，依序切換並循環。場景先以色調區別，保留獨立圖層供後續替換美術。

圖片挑戰隱藏檔名，點擊圖片可放大；即使沒有參考答案，也可直接點「答對了」獲得經驗。「再試一次」保留原題、收起答案，不扣經驗。點擊頭像可上傳玩家圖片。「重置進度」會經確認後清除步數、等級經驗與場景進度，保留題庫、頭像及門檻設定。

`npm test` 驗證路徑、事件格、場景答題門檻與重置資料保留。

## 獎勵、題庫與主題

冒險設定可調整每題獎勵（0–10000 EXP），每次獲得經驗同額累積星星。失去經驗不扣星星；重置進度會將兩者歸零。可選擇啟用的資料夾（含未分類），沒有啟用題目時會提示並開啟題庫，不會擲骰抽到停用題目。新資料夾預設啟用。主題色會影響按鈕、標誌與介面重點色，並保存在目前瀏覽器。

達到場景門檻後，下一格出現魔法陣；再擲骰時會顯示骰子點數，並明確提示魔法陣接引前進一格，逐格走上魔法陣後轉場。機會與命運使用直式卡牌，確認後結算一次獎勵。

正式建置會將程式合併成單一傳統腳本，程式與 CSS 使用內容雜湊檔名以避免跨版本快取混用；包含 .nojekyll。瀏覽器載入失敗會顯示提示。正式版本應測試打包後的 /EN-game2/ 子路徑，而非僅驗證開發伺服器。

# 苔光之境 · Mosslight

桌面版奇幻像素 RPG 學習網站。正式網址：https://harriet-pixel.github.io/EN-game2/

## 開發與發布

使用 Node.js 24，無需安裝外部套件。

```sh
npm run dev
npm test
npm run build
```

開發伺服器預設使用 3000 埠，可透過 `PORT` 修改。`npm run build` 產生 `dist/`；推送至 `main` 後，GitHub Actions 依序測試、建置及部署至 GitHub Pages。JavaScript、CSS、設定與核心素材有內容版本識別。

## 探險與題庫

- 左側導覽提供冒險地圖、更衣室、寶石圖鑑、我的題庫與冒險設定。
- 骰子位於探險畫面右上方，可按空白鍵擲骰。點數確定後保持不動，角色逐格前進；接近畫面邊界時由鏡頭向右平移。
- 石階包含題目、機會與命運。答滿所有場景共用的門檻後，下一次擲骰會走上魔法陣，領取配件獎勵再進入下一場景。
- 每題答對在 Min／Max 範圍內隨機獲得同額經驗與星星，每 100 EXP 升級。升級會播放動畫並提供配件抽卡。
- 未處理的題目不能直接關閉；再次擲骰會開啟同一題。「再試一次」不計為已作答，也不發放獎勵。
- 題庫可上傳圖片，管理資料夾名稱、順序、刪除與批次移動。可設定是否重複出題，並清空作答紀錄。
- 挑戰圖片預設自動符合螢幕高度，支援滾輪縮放與符合寬度。無參考答案也能自行判定答對。
- 機會與命運內容在「我的題庫」的獨立頁籤設定。

## 更衣室與配件編輯

配件分為髮型、眼睛、衣服與寵物。每件使用一張 PNG、WebP 或 SVG，可同類批量上傳、逐件更名，調整位置、等比例尺寸與圖層，也可多選套用版型。

更衣室左側提供紙娃娃預覽，已獲得配件排在上方，未獲得配件在下方。預覽寬度、共同裁切方式與未獲得灰色遮罩可在更衣室設定調整；寵物使用原始圖檔預覽。

髮型、眼睛與衣服可各指定一件初始預設，初始即解鎖。抽卡依四大類的設定比例抽選，再於該類尚未獲得的配件中等機率選取。翻卡後可選擇立即套用，領取後繼續冒險。

角色使用全身底模；穿戴或編輯衣服時使用獨立的人偶頭，衣服圖片本身包含四肢。更換底模、上傳配件與 SVG 安全處理均在獨立編輯室進行。

## 寶石、音效與外觀

預設提供八色、每色二十形狀，共 160 顆寶石。共用形狀名稱，稀有度依形狀位置固定；每個顏色可設定普通、稀有、傳說三種名稱。可上傳大圖並拖曳裁切格線，或上傳單張寶石圖。新增顏色可刪除，預設八色保留。

寶石掉落機率與稀有度比例在圖鑑的「寶石與音效設定」調整。挖到寶石時先播放兩秒文字動畫與音效，再顯示稀有度卡牌。

角色台詞與配音可依情境逐項設定，支援 `.ogg` Vorbis 等音訊格式，每檔上限 10 MB。圖片上傳支援 WebP。

提供黑曜、粉晶與冰湖三種主題。可調整玩家名稱、角色大小、骰子大小與網站字級，並預覽探險畫面。五種場景底圖依序循環，設定統一儲存。

## 最新預設與檔案

`default-state.json` 是目前發布的設定與收藏資料；首次使用會開啟全新冒險，只有指定的預設造型解鎖。

- `assets/base-body.webp`：全身底模。
- `assets/head.webp`：服裝用人偶頭。
- `assets/stone.webp`：石階。
- `assets/portal.png`：魔法陣。
- `assets/forest.webp`：預設背景。
- `assets/defaults/`：配件、場景、寶石與音檔，以內容雜湊命名，重複檔案共用。
- `assets/fonts/`：jf open 粉圓字型與授權。

所有預設圖片與音檔保留提供的原始格式與內容，不轉換、不重新壓縮。啟動時等目前場景、角色、石階與字型準備好後才顯示探險畫面。只有進入相關功能時才載入其餘素材。

預設圖檔包由建置自動產生於 `downloads/EN-game2-default-images.zip`，只在使用者點擊下載時傳送。`scripts/prepare-defaults.mjs` 可將經確認的備份整理成正式預設；只需在刻意更新預設時執行，不會在一般部署時自動執行。

## 儲存、備份與重置

目前使用瀏覽器 IndexedDB `mosslight-current`，新產生的進度與設定在重新整理後保留；不同瀏覽器或裝置之間不會自動同步。成功啟動後會清理已退役的網站儲存區；若被其他分頁占用，關閉那些分頁即可完成。

完整 JSON 備份包含設定、題庫、全部圖片、音檔、配件與寶石進度。匯出時會將網站素材完整內嵌，還原不依賴原裝置。還原會取代目前瀏覽器資料；匯入網站不會自動發布成其他裝置的預設。

重置進度會清除經驗、星星、步數、作答紀錄、頭像、非預設配件解鎖與寶石收集；題庫、上傳素材、底模及設定保留。星星總數也可獨立歸零，不影響經驗。

測試使用 `tests/` 與 `test-support/doll-fixture.js`，不會發布到網站。`/fantasy-test/` 僅轉址至正式版，沒有獨立的遊戲或儲存區。Git 提交歷史保留。

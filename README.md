# 苔光之境 · Mosslight Fantasy

高細節奇幻像素 RPG 學習網站。正式網址：https://harriet-pixel.github.io/EN-game2/

## 開發與發布

使用 Node.js 18 以上，無外部套件、API 金鑰需求。

```sh
npm run dev
npm test
npm run build
```

開發伺服器預設 3000，可用 PORT 環境變數修改。正式建置輸出 `dist/`，可部署至 GitHub Pages 或一般靜態服務。GitHub Actions 在 main 推送後自動測試、建置、部署。程式與 CSS 使用內容雜湊檔名，避免版本混用。

## 遊戲與設定

- 骰子位於場景中央，也可使用下方擲骰按鈕；逐格移動。場景名稱只在初次進入與穿越魔法陣進入新場景時短暫顯示。
- 每屏八塊石階，路徑持續延伸。到達最右側後暫停走路，鏡頭平滑往右移，使人物原本站立的石階成為第一顆，再走完剩餘步數。背景採較慢速度平移。
- ✧ 題目、✦ 機會、☽ 命運。機會／命運使用直式卡牌，確認後結算獎勵；不計入答題數。
- 所有場景共用一個答對門檻（1–1000），遊玩中可修改並保留已答對數。答滿門檻後開啟魔法陣，下一次擲骰接引前進一格，走上魔法陣後才轉場。
- 答對獲得設定的經驗（0–10000），正向經驗同額累積星星，每 100 EXP 升級；失去經驗不扣已累積星星。
- 左側「冒險設定」提供黑曜介面、共用題數、獎勵、啟用題庫與重置進度。
- 重置會清除等級經驗、星星、步數、場景答題數、頭像與寶石圖鑑；保留題庫、配件與設定。

## 圖片題庫

支援資料夾、搜尋、批次上傳／移動／刪除，及編輯題目與答案。單張圖片上限 20 MB，上傳縮至最長邊 1600px。可點擊頭像上傳個人圖片。

挑戰不顯示檔名；沒有參考答案仍可直接判定答對。「再試一次」保留原題並收起答案。點擊題目圖片會開啟全螢幕檢視器，預設符合可用螢幕高度。滑鼠滾輪調整符合高度尺寸的 10%–800% 比例，保留游標附近的位置；也可使用放大／縮小及符合高度按鈕。寬圖或放大後可捲動查看。

## 資料與素材

正式版沿用 `mosslight` IndexedDB；既有題庫、頭像與進度會保留。舊版各場景獨立題數會以目前場景的門檻遷移為共用題數。舊自訂主題色升級為預設黑曜版。所有資料僅屬於目前瀏覽器與來源，不支援跨裝置同步；清除網站資料會移除內容，請保留原始圖片。

`assets/forest.webp`、`assets/stone.webp`、`assets/base-body.webp`、`assets/head.webp`、`assets/portal.webp` 是目前使用的無損網頁圖檔，原始 PNG 另行保留。`fantasy.css` 提供奇幻黑曜樣式。人物使用底模與配件分層搭配移動動畫；五個場景預設以色調區分，可各自上傳底圖。

舊美術測試網址 `/EN-game2/fantasy-test/` 仍可使用，繼續使用獨立的 `mosslight-fantasy-preview` 資料庫，不會覆寫正式版。

## 紙娃娃更衣室與獨立編輯室

更衣室分為髮型、眼睛、衣服、寵物四類，以 `assets/base-body.png` 底模疊加配件。每類可穿戴一件配件，整體依各配件的圖層數值排序；底模固定為 0，負值可放在底模後方。穿戴會同步到地圖角色、預設頭像及更衣室預覽，自訂上傳頭像另行保留。

配件預設全部鎖定，包含自行上傳的配件；勾選為初始預設並儲存的配件例外，會直接解鎖與穿戴。新裝置不包含示範髮型、眼睛或服裝，僅保留預設寵物。編輯室不受穿戴鎖定限制：先點「編輯配件」，再選髮型／眼睛／衣服／寵物；支援批量上傳 PNG、WebP 或 SVG（單張 10MB，邊長不可超過 10000 像素）、拖曳位置、X/Y、等比例縮放及圖層順序調整、命名、刪除。位置和大小使用畫布百分比；配件鎖定原始圖檔比例，透過右下角把手、滾輪或 ＋／− 縮放，寬高欄位僅供顯示。原圖尺寸會保留，舊配件在選取編輯時會讀取原圖比例。未儲存的調整在離開時會詢問是否捨棄。

可在編輯室更換 Base Body PNG／WebP／SVG，方便使用原始底模。SVG 會移除腳本、外部來源與不支援的元素；建議以向量路徑匯出，含內嵌點陣圖的 SVG 請改上傳 PNG 或 WebP。

達成場景答題門檻後，擲骰走上魔法陣，先跳出三張蓋牌。選一張翻開，獲得一件尚未解鎖的隨機配件；收下後才進入下一場景。配件不會自動穿戴，可在更衣室選擇。三張卡與已選結果會儲存，重新整理不會重抽或重複領獎。所有配件都收集後，改贈 25 星星。重置冒險會回到預設造型，只保留預設配件的初始解鎖；上傳素材與版型保留，其他配件需重新取得。

「冒險設定」可修改玩家名稱（最多 20 字，不能空白），同步顯示於玩家資訊及更衣室。原先完整角色素材仍保留在 assets/ 中，當前角色改用紙娃娃分層合成。

骰子僅在產生點數時晃動，點數確定後立即停止；人物行走期間保持相同點數、固定位置與不透明骰面。

### 同類批次編輯與預設組合

同一類型可一次選取多張 PNG／WebP／SVG 上傳。每張各自儲存原始尺寸、位置、縮放與圖層。上傳後從第一件開始，可用上一件／下一件或「儲存並編輯下一件」逐件處理；批次順序與調整狀態會保留。配件選擇改為縮圖彈窗，點選圖檔即可切換，不使用下拉選單。未儲存切換仍會詢問是否捨棄。

每類可勾選一件「預設配件」，組成初始造型。儲存後立即解鎖並穿戴，不需從卡牌抽取；同類原先的預設會取消，但已取得配件不會被收回。更衣室提供「更衣室設定」彈窗，調整縮圖寬度與裁切方式；偏好自動儲存。重新整理會保留目前穿戴；重置冒險不刪除預設。

預設及上傳素材仍屬於目前瀏覽器的本機資料，不會自動同步到其他玩家的裝置。

## 單張髮型與配件檔案展示

新增髮型與其他配件一樣，每件只需一張 PNG／WebP／SVG，可同類批量上傳、逐件編輯名稱及版型。原先已儲存的前／後髮組仍可穿戴及編輯，不會刪除舊素材；新版不再提供新增雙圖髮型表單。

更衣室只顯示配件圖檔，不將底模或其他穿戴配件疊入縮圖。未解鎖圖檔維持原色，標示「尚未解鎖」，無法穿戴。已解鎖配件優先排列，其餘保持原本順序。配件名稱只能在編輯室修改。穿戴結果在冒險畫面顯示。

## 160 種可擴充寶石與挖掘

上方「寶石圖鑑」預設包含八色 × 20 形狀，共 160 顆寶石：普通 96 種、稀有 48 種、傳說 16 種。新增顏色會自動增加 20 顆。可依稀有度、已蒐集狀態與名稱／編號篩選，點擊看細節。相同寶石再次獲得會累計數量，不增加已發現種類數。

每次按「答對了」完成一道題目後挖掘一次；再試一次、關閉題目與機會／命運事件不挖掘。先依「每題挖到寶石的機率」判定是否掉落，再依三種稀有度的比例選擇類型，最後在該類型中均勻抽取一顆。完成同一題的重複點擊不會重複領取。

「寶石圖鑑 → 寶石與音效設定」可調整兩層機率，掉落率可為 0–100%，三種稀有度必須合計 100%。預設每題掉落率 30%，挖到後普通／稀有／傳說分別為 75%／20%／5%。例如每題得到傳說寶石的實際機率為 30% × 5% = 1.5%。設定儲存後從下一題生效。

寶石收藏、數量、挖掘次數與設定儲存在目前瀏覽器，重新整理會保留收藏；重置冒險會清空收藏、數量與挖掘紀錄，但保留掉落機率設定。

## 套用到多個配件

在編輯室調整來源配件後，點「套用到多個配件…」開啟全部配件縮圖，可搜尋名稱／類型、多選或全選目前顯示的目標。位置與縮放預設勾選，也可另外選擇圖層順序。縮放以來源寬度為準，目標圖檔維持自己的原始長寬比例，高度自動計算。

不更改目標名稱、圖片、解鎖、預設或穿戴狀態。來源使用目前預覽值，但來源本身未儲存的編輯仍須另行儲存。既有雙圖髮型保留前後髮的相對位移與圖層差異。設定成功後，目標更新會保存並同步到已穿戴的配件。

## 五種自訂場景底圖與載入效能

「冒險設定」下方提供五個場景欄位，可編輯名稱、上傳圖片及還原預設底圖，再按統一儲存設定套用。名稱最長 40 字，圖片上限 20 MB。上傳時由瀏覽器限制最長邊 2000px；符合尺寸限制的 WebP 保留原檔，其他圖片或超限圖片轉為 WebP（品質 0.9）；存於目前瀏覽器，不自動同步其他玩家。輪替順序為 1 → 2 → 3 → 4 → 5 → 1，仍須達到共用答題門檻、走上魔法陣並收下配件卡牌後轉場。自訂底圖使用原本顏色，不套用預設場景濾鏡。

主要美術從 PNG 改用逐像素驗證無差異的無損 WebP：森林 2,992,352 → 2,426,718 bytes、石階 1,424,476 → 1,034,324 bytes、底模 561,520 → 352,924 bytes，合計減少約 23%。首次仍須下載約 3.81 MB 的主要圖檔；實際等待受網路與裝置影響。

初次載入優先取得森林底圖，顯示場景載入提示，空閒時預載下一張；不再下載未使用的舊角色美術。角色與頭像合成使用快取，人物每次移動不會重建相同圖片元素。配件、題庫與圖檔選擇縮圖延後至接近可見時載入。石階符號在桌面放大至 44px，手機 30px；魔法陣圖像獨立顯示在目標石頭上方、角色後方。

### 備份與顯示設定

冒險設定可下載／還原完整 JSON 備份，包含題庫圖檔、頭像、底模、配件、五個場景底圖、內建圖片、寶石收藏、進度與設定。還原驗證通過並確認後，以單一 IndexedDB 交易取代資料；建議還原前先下載現有備份。備份上限 250 MB。

角色大小可設為 50–200%。重置進度會清除自訂頭像，保留題庫、配件與設定，並清空寶石圖鑑、數量及挖掘紀錄。更衣室左側顯示即時紙娃娃預覽，右側各類上方為已獲得、下方為未獲得，以橫線分隔。「更衣室設定」可調整預覽寬度 80–260px；共同裁切會依同類配件設定後的可見範圍取聯集，保持相同比例，不更動原始素材或穿戴位置。也可切回原始圖檔預覽。配件更名僅在編輯頁面進行。冒險設定可調整全站字級 80–150%，預設 100%；角色對話框會依角色大小移動並避開玩家資訊卡。

### 題庫管理與獎勵流程

「我的題庫 → 管理資料夾」支援更名、刪除與上下排序。更名會保留啟用狀態；刪除資料夾會將題目與圖片保留在「未分類」。排序會同步用於題庫清單、移動選單與冒險設定，並包含在備份中。

更衣預覽採左側黏附定位，批次選題工具列保留位置，頁面保留捲軸空間，避免操作導致版面跳動。

挑戰圖片預設符合可用螢幕高度，仍可滾輪縮放。答對按鈕只顯示「答對了」，先通知獲得星星，再播放升等彩帶動畫與三選一配件獎勵。每跨過一級提供一次抽卡；升等獎勵不切換場景，魔法陣的獎勵仍獨立觸發。通知與未領卡牌會儲存，重新整理不會重複發獎。

### 寵物與配件抽選機率

第四類改為寵物，沿用紙娃娃的上傳、位置、尺寸、圖層、預設與穿戴機制。舊鞋子類別的上傳素材、解鎖狀態、穿戴與抽卡紀錄會遷移保留；未修改的系統短靴示範素材更新為小貓。

冒險設定中依髮型、眼睛、衣服、寵物四大類設定抽選相對比例（0–100），並查看目前百分比。沒有未獲得配件或比例為 0 的類型不參與抽選；抽中類型後，該類未獲得配件等機率抽取。舊逐件設定會合併為大類比例。全部設為 0 或已取得全部配件時，改贈 25 星星。升等與魔法陣共用機率，已產生的卡牌不受設定變更影響。

### 全身與衣服頭部底模

一般使用全身底模。編輯衣服或穿戴衣服時，改用僅頭部的底模，避免與服裝圖檔的軀幹及四肢重疊。預設頭部為獨立的 head.webp（1086×554），以原本 1086×1448 畫布的頭部位置與比例顯示，配件位置不需重設。編輯室可分別更換全身底模與衣服頭部底模，兩者皆包含於備份。

更衣室配件卡不顯示配件名稱，名稱保留於編輯頁面。骰子位於場景右上角，與角色狀態框同高，前進步數以同色文字顯示在角色頭頂上方並跟隨移動；角色腳底與影子共用固定支點，縮放時保持接觸。

### 寶石發現與抽卡穿戴

設定中可上傳每色的 5×4 寶石大圖，一次裁切 20 顆並依位置配對形狀；也支援批量上傳單張素材，優先填入尚未自訂的圖示，保留蒐集數量。可逐張還原系統圖片。自訂圖片、發現音效與內建魔法陣／音效都包含在備份；重置進度會清空收藏與非預設配件解鎖，不刪除素材。

答對先顯示星星通知；如有挖到寶石，播放 2 秒「Wow! What's this」逐字動畫與神秘音效，再顯示寶石卡牌。內建音效為 2 秒 WAV，也可上傳 10 MB 以下的自訂音檔。提示為無視窗純文字；若瀏覽器阻擋自動播放，可點文字播放音效。關閉寶石卡牌後才繼續升等獎勵。

配件卡牌使用七彩邊框，顯示與更衣室一致的配件單圖及共同裁切範圍，不含角色底模。選卡領取後，須選擇「立即套用」或「稍後再說」；選擇會隨未完成卡牌儲存，接著自動關閉視窗；魔法陣獎勵直接轉往下一場景，升等獎勵回到目前場景，不需再按收下按鈕。髮型、眼睛、衣服若有預設配件，卸下其他配件時會換回預設，預設本身不可卸下；寵物仍可卸下。

場景右上方的地點文字、冒險頁標題下的紫藤說明與下方冒險足跡／擲骰控制列已移除。對話框與字級放大三倍。進入下一場景時步數與視窗起點回到第一顆石頭，魔法陣不再使用石頭上的符號。

### 寶石顏色、形狀與快速裁切

預設顏色依序為 Green、Brown、Gold、White、Pink、Blue、Red、Purple。每色可設定普通、稀有、傳說三個名稱前綴；形狀名稱只有一份 20 格設定，按橫 5、直 4 的固定位置共用。第 1–12 格為普通、13–18 格為稀有、19–20 格為傳說。名稱為該色對應稀有度前綴加形狀名稱，例如紅色第 1 格「火焰月影」、第 13 格「玫瑰六芒」、第 19 格「薔薇永恆」。新增顏色只需填顏色名稱、三個前綴並上傳大圖，不需重設形狀名稱。

大圖支援 20 MB 以下 PNG、JPEG、WebP（最長邊 12000px、總像素不超過 6000 萬），可在同一排設定四邊邊界、直接拖曳各條格線，並設定欄列與每格尺寸，預覽每格名稱後一次裁切 20 張圖片（WebP 大圖輸出 WebP、品質 0.95；其他來源輸出 PNG；每格最長邊上限 1024px）。原始大圖、裁切參數、分割圖片與名稱皆包含於備份，還原後仍能重新裁切。既有寶石編號 001–100 的蒐集數量及圖片會保留，依新位置規則重新分類。

### 統一設定與黑曜介面

設定頁以左側導覽分為玩家冒險、顯示外觀、配件抽卡、場景、備份重置。角色大小、網站字級與骰子尺寸放在一起，在完整探險畫面中即時預覽。場景名稱與底圖先暫存，按左側導覽底部或頁面最下方的儲存按鈕統一套用。寶石大圖、顏色名稱、形狀名稱及音效改於寶石圖鑑右上方「寶石與音效設定」彈窗獨立儲存；備份匯出只包含已儲存資料。星星歸零為獨立操作，不更動經驗、等級與收藏。

更衣室的預覽黏附在左側，不顯示預覽標題與提示文字。網站統一使用黑曜版。普通寶石卡使用簡潔框線、稀有為紫晶雙框、傳說為厚框與星光裝飾，使用金色裝飾。

### 出題、事件與每日統計

冒險設定可決定是否重複出題。所有答對題目皆會記錄 ID；禁止重複時，只從啟用資料夾中的未完成題目抽選。重試、關閉挑戰不算完成。「清空已作答紀錄」會保留題庫與圖片，使題目可重新出現，不清除經驗或星星。

在「我的題庫 → 機會與命運」頁籤可各自新增、刪除事件，編輯標題、內容、經驗變化，按「儲存機會與命運」獨立套用；未儲存離開會提醒。正數經驗同額增加星星，負數不扣星星；兩類都可設為空。探險頁上方顯示配件／寶石收藏、星星總數及當日獲得星星；當日以 Asia/Taipei 日期計算，總星星歸零不影響當日獲得量。

預覽、配件縮圖與編輯畫布皆為正方形，紙娃娃預覽自動取完整角色與配件範圍縮放，保留原有座標及圖層，避免寵物超出畫面。抽卡不顯示配件名稱。寶石發現提示為純文字「Wow! What's this」，每個字母移動，播放 2 秒後顯示寶石卡牌。

裁切保留 20 格形狀順序，可選 5×4、4×5 等欄列組合，調整每格大小及拖曳個別邊界。格線位置與網格尺寸包含於備份。預設八色不可刪除；新增顏色可刪除，其素材與蒐集紀錄會在儲存設定後移除。

「重置進度」為重新開局：清空經驗、星星、當日累積、作答紀錄、頭像與寶石收藏；非預設配件重新鎖定，角色穿回預設造型。題庫、配件素材、底模、寶石大圖、裁切設定、事件與其他設定保留。

### 最新介面與備份

骰子以狀態框高度的三倍顯示。圖片題開啟時預設自動放大，依可用螢幕高度填滿；右上「符合螢幕寬度」可切換，滾輪繼續縮放。冒險設定可關閉自動放大。未儲存的冒險設定在切換頁籤或離開網站前提醒，寶石設定關閉前也會提醒。

更衣室顯示放大的夢幻玩家名稱與解鎖數量，預覽偏好收進「更衣室設定」彈窗；寵物縮圖與抽卡預覽使用原始圖檔，不共同裁切。角色與配件預覽底色皆為白色。

全站使用 justfont 免費 jf open 粉圓 2.1，字型隨網站託管，不依賴外部字型服務。來源：https://github.com/justfont/open-huninn-font ，SIL Open Font License 隨附於 assets/fonts/OFL.txt。

完整備份包含自訂與內建發現音檔，JSON 內嵌資料，還原後可直接播放。已以隔離瀏覽器實測上傳 WAV → 匯出 → 改回內建 → 還原，確認音檔內容一致且可解碼播放。

### 左側導覽與答題流程

主要導覽固定於左側。「我的題庫」分為圖片題庫、機會與命運兩個頁籤；事件設定與冒險設定各自儲存，互不覆寫。冒險收藏列最左側顯示七彩等級與經驗條；場景左上只顯示放大的頭像圓框及玩家名稱。當日星星仍照原規則累積，移除時區提示文字。角色可見圖底（底模腳底基線）與影子中心固定對齊目前石頭圖的上緣，縮放維持同一基準。

探險時按空白鍵可擲骰；輸入欄、其他頁面、作答視窗與獎勵播放中不會觸發，長按不重複擲骰。骰子以向量圖示消除字型留白，上、右框線各留一個字元的間距，最終點數維持不動。

旅途挑戰沒有關閉叉號，Esc 無法關閉，未處理前骰子鎖定。選「答對了」記錄完成並發獎勵；選「再試一次」直接關閉、不記錄已作答、不給經驗／星星／寶石，繼續擲骰。未完成題目的 ID 會儲存，重新整理仍需繼續處理；重置進度清除續答狀態。

更衣室左側正方形角色預覽加大（桌面欄寬上限 440px），仍自動納入寵物範圍；移除右側造型提示文字。寶石與音效設定儲存成功後自動關閉，驗證或儲存失敗時保留視窗。圖片符合螢幕寬度時垂直置中，超高圖片從中央位置開始並可捲動，滾輪縮放保留游標錨點。

### 骰子尺寸與未完成挑戰復原

冒險設定的「顯示與外觀」提供骰子大小 25–150%，100% 為原尺寸，附即時預覽，儲存後套用並隨備份保留；舊資料預設 100%。骰子上、右一字元間距維持不變。

旅途挑戰設為不可原生關閉，並攔截 Escape 的 keydown、keyup 與 cancel；放大的圖片仍可先按 Esc 返回題目。若瀏覽器意外關閉挑戰，未完成題目仍儲存，骰子按鈕或空白鍵會重新開啟同一題，不抽新點數、不移動、不給獎勵，優先於魔法陣與題庫篩選。答對或選「再試一次」後才能開始下一次擲骰。

「顯示與外觀」以目前的完整探險畫面取代個別角色／文字／骰子樣本，包含目前穿搭、頭像、收藏狀態、石階與背景。角色、骰子與字級即時套用於預覽，依可用寬度等比縮放；預覽與遊戲共用角色接地、對話框位置及樣式，且不觸發擲骰、不修改進度。未儲存的調整只影響預覽，保留原有離開提醒與統一儲存。

### 角色台詞與配音

角色對話框與箭頭使用不透明白色填色、黑色文字。冒險設定新增「角色台詞與配音」及左側導覽，可逐項修改下列預設台詞：

| 情境 | 預設台詞 |
| --- | --- |
| 開始／重新出發 | 冒險，出發！ |
| 遇到題目 | 發現新挑戰！ |
| 答對題目 | 答對了！我們又前進了一步！ |
| 再試一次 | 沒關係，下次再挑戰！ |
| 遇到機會 | 遇見機會！會有什麼驚喜呢？ |
| 遇到命運 | 命運降臨！讓我們一起面對。 |
| 開啟魔法陣 | 魔法陣開啟了！準備前往下一個場景吧！ |
| 抵達魔法陣 | 魔法陣在閃耀！來選一份禮物吧！ |
| 進入新場景 | 歡迎來到{scene}！新的冒險開始了！ |
| 升等 | 升到第{level}級了！一起繼續成長吧！ |

台詞最多 300 字，留白隱藏對話框，支援 {player}、{scene}、{level}、{stars}。各情境可上傳 10 MB 以下配音、試聽與移除，並提供全域播放開關；配音播放原始錄音，不將變數轉成語音。新台詞中斷前一段配音，切換頁面停止播放；寶石發現音效前停止角色配音以免重疊。若瀏覽器阻擋自動播放，點擊角色對話框可重播。

台詞與配音隨冒險設定統一儲存，離開未儲存時提醒。完整備份內嵌配音並驗證，舊備份自動補齊預設台詞；重置進度保留自訂台詞與配音。

魔法陣以 2.6 秒循環上下浮動，減少動態效果偏好下停止浮動。「前進 N 格」與「Wow! What’s this」使用相同的響應式字級。角色定位以石頭上緣及可見腳底基線為準，排除底模透明留白，50–200% 尺寸與完整場景預覽共用定位；移除行走時的垂直跳動。

粉色版的寶石篩選、圖鑑與出現視窗按鈕、文字改用紙娃娃的粉色系。更衣室設定可選擇未獲得配件加上灰色遮罩，預設關閉，自動儲存並隨備份保留。已獲得配件依保存的整體取得順序排序，縮圖下方置中顯示 #001 等編號；跨分類共用同一編號，未獲得不預編號。重置進度後從預設配件重新編排。

配件翻卡後使用放大的正方形白底預覽，延續更衣室的裁切與原圖偏好；桌面卡牌加大以容納預覽，手機仍保留三張卡牌。更衣室、編輯器與抽卡的角色／配件預覽統一白底。

### 隨機答題獎勵與逐句配音

每題答對可設定 Min／Max（0–10000 整數，Min 不得大於 Max），答對時在含上下限的範圍內均勻抽取一次。經驗、星星、當日累計、升等判定、通知與台詞 {stars} 使用同一個實際抽取值；Min 等於 Max 即固定獎勵。舊設定自動遷移為原固定值，備份保留範圍，重置進度保留設定。

配件抽卡選「立即套用」或「稍後再說」後自動關閉視窗並完成獎勵流程，轉場期間鎖定操作以避免重複領取。魔法陣進入下一場景；升等抽卡維持目前場景。無配件可抽的星星替代獎勵仍使用收下按鈕。

前進文字位於角色頭頂上方，逐幀跟隨移動，圖層高於角色。角色台詞設定各自提供 28px 的配音勾選框，關閉單句配音不會刪除音檔，仍可手動試聽；總開關關閉時全部情境靜音，各項選擇保留於備份。

### 全部圖片入口支援 WebP

題庫、頭像、五種場景、寶石單圖與大圖、四類配件、舊髮片替換、全身及衣服頭部底模皆可上傳 WebP，含透明背景。選擇器同時接受 .webp 副檔名，沒有 MIME 的 WebP 也會依 RIFF／WEBP 標頭驗證並正確儲存。配件與底模保留原始壓縮資料、尺寸及透明度，支援重新整理與備份還原，不會被舊的 PNG／SVG 篩選排除。

符合尺寸上限的題庫、頭像、場景及寶石單圖 WebP 直接保留原檔，不重複編碼；超過尺寸上限才縮小。WebP 寶石大圖保留原檔，裁切結果也用 WebP 儲存；其他大圖維持 PNG 裁切結果。既有圖片不自動轉檔，原有檔案與像素上限保留。

### 新裝置內建圖檔

內建服裝用頭部改為獨立 head.webp，原樣截取全身底模頂端 1086×554，無損 WebP 像素比對為零差異。魔法陣改用 portal.webp，亦經無損像素比對。新裝置移除示範髮型、眼睛、服裝，保留月光小貓；既有資料與舊備份只移除相同 ID 且仍為原始示範圖檔的項目，保留上傳或替換後的素材與進度。頭部與魔法陣一併包含於完整備份；舊備份缺少頭部時使用網站內建檔。

正式建置不再打包未使用的舊人像與原始 PNG，美術備援改用全身 WebP。可執行 `node scripts/export-default-images.mjs` 匯出新裝置使用的全部 172 張圖檔：5 張主要 WebP、1 張預設寵物 SVG、160 張預設寶石 SVG、6 張骰子遮罩 SVG，附用途清單。介面框線、對話框、陰影及文字圖示由 CSS／字元繪製，沒有其他圖檔。

### 公開圖檔包下載

每次 `npm run build` 自動從目前預設素材產生 `dist/downloads/EN-game2-default-images.zip`，公開網址為 https://harriet-pixel.github.io/EN-game2/downloads/EN-game2-default-images.zip 。冒險設定的備份區提供下載連結，測試版亦指向同一檔案。圖檔包不會在一般遊玩時預載；建置會清除暫存來源目錄，只發布 ZIP。下載包使用 Node 24 內建壓縮及 CRC，包含 UTF-8 檔名並保留原始圖檔內容。

上傳與匯入備份只更新目前瀏覽器的 IndexedDB，不會改變網站預設素材或發布內容；原網站檔案仍存在，完整備份也會包含內建及自訂素材。若將個人設定製作成全新裝置的預設版本，應將備份作為交付來源，抽出圖片／音檔、去重與移除未使用素材，再發布以路徑引用的設定；避免整包 Base64 內容都成為每次必載資料。這是發布整理流程，目前介面的匯入不會自動執行。

### 黑曜主題與 Chrome 預覽相容性

移除櫻花粉選項與其專用樣式，既有瀏覽器及舊備份的粉色設定統一轉為黑曜，其他素材、設定與進度保留。探險預覽以含 DOCTYPE 的標準模式文件載入，與正式頁面一致；等待樣式及字型載入完成後才顯示，初始先設定與主頁相同的視窗寬度，維持相同媒體查詢。

預覽 iframe 本身不縮放，改由外層畫布統一縮放與裁切，排除 iframe 捲軸差異造成的偏移。主頁保留穩定捲軸空間，減少切換頁面時的寬度跳動。已在 Chrome 的一般／Retina 倍率及六種視窗尺寸驗證即時調整、儲存與原探險畫面的對應、未儲存提醒及舊設定遷移。圖檔包仍含完整 172 張素材。

### Ogg Vorbis 音檔

角色各情境配音與寶石發現音效皆支援 .ogg（Vorbis），選擇器明確接受 audio/ogg、application/ogg 與 .ogg／.oga 副檔名。未提供 MIME、使用 application/ogg 或附帶 codecs 參數時，驗證 OggS 標頭後統一儲存為 data:audio/ogg；保留原始壓縮內容，不重新轉碼。原有其他 audio/* 格式及每檔 10 MB 上限維持。已以實際 Vorbis 編碼檔測試試聽、遊玩播放與完整備份還原。

### Published default preset

`default-state.json` contains the owner’s reviewed settings and collection metadata. On a browser with no saved game it initializes a fresh adventure with only default outfit pieces unlocked. Existing browser saves remain authoritative. Uploaded media lives in `assets/defaults/` under SHA-256 filenames, is loaded as needed, and is embedded back into exported backups for offline portability. PNG accessories were converted to lossless WebP; audio bytes are preserved. The configured body and head replace `assets/base-body.webp` and `assets/head.webp` directly. The five configured scene backgrounds and all character voice lines are included.

To intentionally regenerate the preset, run `node scripts/prepare-defaults.mjs /path/to/reviewed-backup.json` from the repository root (requires ImageMagick `convert`), then review the generated diff and run tests/build. Never commit the raw backup; it duplicates the extracted media and may include private play data. The generated preset clears progression, acquired gems, avatar and pending rewards. Uploading/importing a backup in the website remains local to that browser and does not publish it.

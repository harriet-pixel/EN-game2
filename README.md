# 苔光之境 · Mosslight Adventure

桌面優先的像素 RPG 學習網站，無需 API 金鑰或外部套件。

## 啟動

Node.js 18 以上：

```sh
npm run dev
```

預設連接埠 3000，可使用 PORT 環境變數調整。`npm run build` 產出可部署於靜態網站服務的 `dist/`。

## 功能

- 12 格石階、骰子 1–6 點、逐格人物動畫與抵達後隨機挑戰。
- 每次自評答對獲得 25 EXP，每 100 EXP 升級；到達終點可重新探索。
- 批次上傳圖片（單張 20MB 以內，縮至最長邊 1600px）、資料夾分類、編輯題目答案、搜尋、批次移動與刪除。
- 使用 IndexedDB 儲存題庫與冒險進度。資料屬於此瀏覽器與網站來源；清除網站資料會移除進度，請保留原始圖片。
- 背景 `.background-layer`、石階 `.path-layer`、人物 `.character-layer` 為獨立圖層，可分別替換。森林背景為本地 SVG；角色為 CSS 像素圖。

這是純前端版本，沒有帳號、跨裝置同步或自動圖片文字辨識。圖片題目與答案可手動編輯。
